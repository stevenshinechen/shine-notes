# shine-notes

`shine-notes` is a reusable Typst package and starter template for technical
books and lecture notes. It includes book and notes styling, theorem-like
environments, and plotting helpers.

Create a project with:

```sh
typst init @preview/shine-notes:0.1.0
```

The package's layout and some of its mathematical-note conventions are
inspired by [Gabriele Farina's notes](https://www.mit.edu/~gfarina/notes/).
Those notes state that they are licensed under CC BY-SA 4.0. This package is a
modified work by Steven-Shine Chen and is distributed under the same license.
