# Typst book project

This project was created from the `shine-notes` template. Build the book with
`make` and update the package version used by this project with
`make update-package VERSION=x.y.z`.

The template's book layout and some mathematical-note conventions are inspired
by [Gabriele Farina's notes](https://www.mit.edu/~gfarina/notes/), which state
that they are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
